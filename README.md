## 🏗️ Understanding what happens inside

The program uses three powerful technologies working together:

**1. SE(3)-equivariant field model** – This is a fancy way of saying it understands 3D space perfectly. If you rotate your bracket, it still works the same. This makes the AI extremely accurate.

**2. Immersed FEA** – Finite Element Analysis is how engineers test if something breaks. This version does it without messy calculations, so it's fast and reliable—you get certified results in seconds.

**3. Signed distance fields** – Instead of thinking in pixels or triangles, the program thinks in terms of distance from surfaces. This makes shapes perfectly smooth and manufacturable, avoiding tiny flaws that cause real-world failures.

You don't need to understand any of this to use the app. But if someone asks, now you can sound smart.
